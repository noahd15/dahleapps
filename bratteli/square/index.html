Commuting squares

Bratteli diagrams for squares of matrix algebras

Give four finite-dimensional algebras in a square and the four inclusion matrices. The page draws the Bratteli diagram of the square, checks the path-counting conditions a commuting square has to satisfy, and can extend the square to the right with the basic construction. For a single inclusion, see the basic construction page.

C⊂ KD ∪ H∪ L A⊂ GB

Each matrix has one row per summand of the smaller algebra and one column per summand of the larger one, so b = Gᵀa. Rows go on separate lines. A matrix whose shape only fits the other way round is read transposed.

How it works

A square of inclusions A ⊂ B ⊂ D, A ⊂ C ⊂ D is described by four matrices: G for A ⊂ B, H for A ⊂ C, L for B ⊂ D and K for C ⊂ D. Both routes from A to D have to embed A the same way, so the number of paths from a summand of A to a summand of D through B equals the number through C: GL = HK. The page needs this to draw anything.

The square is a commuting square when EBEC = EA for the trace-preserving conditional expectations in D. If it is also nondegenerate (span BC = D), the basic construction gives a new commuting square B ⊂ B1, D ⊂ D1 = ⟨D, eC⟩, and the inclusion B1 ⊂ D1 has matrix H again. For that square to fit together, paths from B to C through A have to match paths through D: GᵀH = LKᵀ. The page checks this too, and only extends the square when it holds. Going further, the vertical matrices alternate H, L, H, … and the horizontal ones alternate G, Gᵀ, … and K, Kᵀ, …

The matrices can't prove the square commutes, because that depends on how B and C sit inside D and not just on their sizes. Take A = ℂ and D = M₂, with B and C both the diagonal ℂ². All four matrices are the same whether C is the diagonal in the standard basis or in a basis unbiased to it. Only the unbiased choice is a commuting square: if B = C, then EBEC = EB ≠ EA. So a pass here means the Bratteli data is consistent with a nondegenerate commuting square. It does not mean the square is one. In general that comes down to whether a biunitary connection exists on the diagram.
